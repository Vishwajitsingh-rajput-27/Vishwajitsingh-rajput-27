# Customization

## Primary files

- `config/profile.json`: personal identity, focus areas, and public links.
- `config/skills.json`: approved and suggested skill visibility.
- `config/projects.json`: repository discovery controls and manual projects.
- `config/integrations.json`: automation mode and feature toggles.
- `config/theme.json`: profile visual theme and palette.

## Workflow behavior

- Set `automaticUpdates.mode` to `direct-commit` or `pull-request` in `config/integrations.json`.
- Keep unknown links empty until publicly verified.
- Keep suggested skills unapproved until portfolio evidence exists.
